# Инструкции проекта

- Текущий этап разрабатывается по принципу Web-first, Android-ready; сохранять возможность адаптации браузерного клиента под Android.
- Используется строго двумерная графика.
- Приоритеты: производительность на слабых устройствах и удобство сенсорного управления.
- Архитектура должна быть модульной; логику симуляции следует отделять от визуального отображения.
- Не добавлять игровые механики без согласования.
- Не переписывать рабочие системы без необходимости. Перед изменениями изучать связанные файлы.
- После выполнения задач проверять результат.
- При изменении архитектуры обновлять документацию.
- После завершения задачи обновлять `docs/STATUS.md`.
- Отчёты Codex должны быть краткими и указывать изменённые файлы, проверки и оставшиеся проблемы.
