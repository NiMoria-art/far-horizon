# Far Horizon

Far Horizon — браузерный прототип двумерной песочницы о развитии цивилизации в космосе. Игрок управляет экспедицией через бортовой ИИ E.O.S. Название ИИ, значения баланса и некоторые игровые параметры пока временные.

**Играть:** [Far Horizon Preview](https://nimoria-art.github.io/far-horizon/)

**Репозиторий:** [NiMoria-art/far-horizon](https://github.com/NiMoria-art/far-horizon)

## Запуск

Нужны Node.js 24 и npm.

```sh
npm install
npm run dev
```

Для production-сборки и локального просмотра:

```sh
npm run build
npm run preview
```

Проверки логики симуляции запускаются командой:

```sh
npm test
```

## Что есть в прототипе

- Двумерная карта звёздных систем с выбором звезды и планет касанием или мышью.
- Постепенное раскрытие сведений о звезде и планетах при сканировании.
- Перелёты внутри системы и между обнаруженными системами.
- Энергия, научные данные, металлы и продовольствие; энергия восстанавливается по мере продвижения игрового времени.
- Три начальных технологических проекта.
- Игровое время и журнал экспедиции.
- Автоматическое сохранение в `localStorage` текущего браузера и адреса сайта.
- Системы процедурно и детерминированно создаются по мере поиска сигнала; жёсткого лимита количества нет. Каталог отображается порциями. Стартовая система H-09 сохранена.

На телефоне разделы интерфейса переключаются нижней навигацией. Карта адаптируется к размеру экрана и поддерживает сенсорное управление.

## Ограничения

Это ранний прототип. В нём пока нет большой галактики, фоновой симуляции реального времени, колоний, населения, других цивилизаций и Android-пакета. Стоимость действий и параметры генерации остаются временными. Число обнаруженных систем на практике ограничивается доступным хранилищем браузера. Capacitor и Service Worker пока не добавлены.
