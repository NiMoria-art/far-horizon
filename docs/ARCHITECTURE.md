# Архитектура

## Цели

Браузерный прототип использует HTML5, CSS3, JavaScript ES Modules, Vite и Canvas 2D. Интерфейс строится из HTML/CSS; Canvas только рисует карту, не хранит игровое состояние. Текущий стек выбран для реализации этого прототипа и не закрывает вопрос о будущей Android-упаковке через Capacitor.

## Структура модулей

- `src/main.js` — создание игры, связывание UI и операций.
- `src/core/` — фабрика состояния, игровое время и шина событий.
- `src/world/` — описания тестовой системы и планет.
- `src/simulation/` — сканирование, ресурсы, перелёт и технологические исследования.
- `src/ui/` — DOM-панели и независимый Canvas-рендерер.
- `src/storage/` — версионированный ключ сохранения в localStorage.
- `src/styles/` — адаптивная визуальная тема.
- `tests/` — проверки игровой логики через встроенный Node.js test runner.

## Поток состояния

Операции симуляции изменяют объект состояния и возвращают результат. `main.js` публикует событие изменения, UI перерисовывает панели, а Canvas получает новое состояние через `render(state)`. HTML-элементы не используются симуляционными модулями. Выбор объекта с карты обновляет выбранную планету в состоянии игры.

## Игровое время

Игровые действия явно вызывают `advanceDays`; Canvas не управляет временем и частотой симуляции. Реального фонового тика, паузы и ускорения пока нет.

## Система и данные

Тестовая система H-09 описана данными в `src/world/planet.js`. Раскрытые поля хранятся отдельно для каждой планеты. Три начальные технологии описаны в состоянии игры; их эффекты применяются симуляционными модулями. Это прототипные параметры, не утверждённый баланс.

## Сохранения

`src/storage/saveManager.js` сохраняет сериализованное состояние под ключом `far-horizon.save.v1`. Ошибка чтения трактуется как отсутствие сохранения; версия предусмотрена для будущей миграции формата.

## Запуск и проверки

- `npm install`
- `npm run dev`
- `npm test`
- `npm run build`

Проверены синтаксис модулей и логические сценарии на Node.js. Проверка интерфейса в браузере и сборка Vite зависят от установки npm-пакетов.

## Ограничения прототипа

Нет фоновой симуляции, генерации систем, зондов, лабораторий, экономики производства, колонизации, межзвёздных переходов или Android-упаковки. Тестовые данные и формулы временные.
